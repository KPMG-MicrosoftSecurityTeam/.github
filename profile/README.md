## About us

<!-- [EDITAR] 2–4 frases. Solo lo que podrías decir en una web corporativa pública. -->

Este espacio de GitHub es la **cara pública** de nuestro equipo. Aquí compartimos
información general, recursos de código abierto y material que puede mostrarse
sin restricciones de confidencialidad.

Trabajamos con el stack Microsoft (Azure, Microsoft 365, identidad, seguridad y
desarrollo) para apoyar a los equipos internos de KPMG en iniciativas de
transformación digital y buenas prácticas de ingeniería.

> **Nota:** Los repositorios y materiales visibles aquí son intencionadamente
> públicos. El trabajo confidencial de clientes y de la firma **no** se publica
> en esta organización.

## How we work (public principles)

<!-- [EDITAR] Principios genéricos; nada de procesos internos sensibles. -->

1. **Public by exception** — Solo publicamos lo pensado para ser público.  
2. **No client data** — Cero datos de clientes, PII o secretos en repos.  
3. **Upstream first** — Preferimos contribuir y referenciar documentación oficial.  
4. **Clear ownership** — Cada repo público tiene un propósito y un README claro.
