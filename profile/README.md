## Quiénes somos

Somos el equipo Microsoft de KPMG en España. Acompañamos a las organizaciones
en la adopción segura de la nube de Microsoft, desde la protección de la
identidad y la información hasta el gobierno de la plataforma y de la
inteligencia artificial.

## Áreas de especialización

| Área | Alcance |
| :--- | :--- |
| **Identidad y acceso** | Microsoft Entra ID, acceso condicional, gestión de identidades privilegiadas y modelos Zero Trust. |
| **Protección de la información** | Microsoft Purview: clasificación, etiquetas de confidencialidad, prevención de pérdida de datos y cumplimiento normativo. |
| **Seguridad y detección** | Microsoft Defender y Microsoft Sentinel para la protección de usuarios, dispositivos y cargas en la nube. |
| **Gobierno de plataforma** | Microsoft 365, SharePoint, Teams y Power Platform: entornos, permisos, ciclo de vida y control del uso. |
| **Inteligencia artificial** | Adopción y gobierno de Microsoft 365 Copilot y Copilot Studio: uso, licenciamiento y control de agentes. |
| **Automatización y analítica** | Azure Functions, Microsoft Graph y Power BI aplicados a la monitorización y el reporting de seguridad. |
